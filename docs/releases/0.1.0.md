# Mae Captions 0.1.0

Initial public alpha of the Mae Captions Python CLI.

## Included

- SRT parsing, structure-preserving chunking, reviewed-English preparation, and multilingual translation pipelines.
- Anthropic, OpenAI, and local OpenAI-compatible LM Studio provider paths.
- Multiple target languages, presets, glossaries, configurable output roots, structured progress events, and offline dry runs.
- Cross-platform Python unit tests, network-blocked smoke testing, repository-content safeguards, and wheel validation.
- Source-available licensing for noncommercial purposes and the qualifying organizations listed in the base license, plus a narrow exception for qualifying independent freelancers.

## Limitations

- Source/CLI release only; no desktop application or prebuilt executable is included.
- No artifact signing or automatic updater is provided.
- Hosted-provider use sends caption text to the selected provider and may incur user-paid charges.
- Platform support is limited to environments where Python 3.12 and the pinned dependencies install successfully; CI covers current GitHub-hosted Linux, Windows, and macOS runners.
- Commercial or business use by a company, agency, partnership, or team requires a separate written license, except for the single-person business vehicle allowed by the Freelancer Exception. Operating Mae Captions as a hosted service or providing hosted access to it, embedded use, commercial redistribution, and commercial use of modified versions also require a separate written license.

## Upgrade notes

This is the first public version. Create a fresh virtual environment and install the package from the repository source.
