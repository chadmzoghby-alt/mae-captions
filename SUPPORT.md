# Support

Use GitHub Issues for reproducible Mae Captions bugs and focused feature requests.

Before opening an issue:

- Confirm the problem occurs on the latest public version.
- Run `mae-captions --version` and include the version number.
- Include the operating system, Python version, provider type, and sanitized command shape.
- Replace caption text with a short original synthetic sample.
- Remove credentials, private paths, provider response bodies, logs, and generated outputs unless each item has been reviewed and sanitized.

Provider billing, account access, model availability, and provider-side policy questions belong with the selected provider. Security vulnerabilities follow [SECURITY.md](SECURITY.md), not the public issue tracker.

For licensing questions, start with [LICENSING.md](LICENSING.md). To request commercial terms, open an issue titled `Commercial licensing contact request` and include only your GitHub handle and a request for a private contact channel. Do not post business details, customer information, proposed pricing, or proposed terms. No commercial permission exists until a written license has been granted.
